# Piloto de Métodos y Resultados en el IDiBE

## Preparación del formador

Prepara dos carpetas equivalentes con un registro de decisiones, un resumen de métodos, las tablas o salidas guardadas que respaldan al menos tres hallazgos y una figura. Usa datos públicos o didácticos de la sesión 3 y añade una referencia publicada con su PDF en Zotero. Incluye dos grupos distintos y un recuento entero para comprobar tanto la atribución como la cobertura.

Comprueba Claude Code, Zotero y Pandoc en el sistema de cada participante. Anota el sistema y las versiones. Incluye al menos un equipo con Microsoft Word para probar la copia que abrirán los coautores. [Materiales del IDiBE](https://github.com/mikelval82/curso-ia-investigadores-idibe/tree/main/sesion3)

## Consigna para el participante

Prepara dos secciones breves de un manuscrito, Métodos y Resultados, a partir de los materiales que tienes. Incluye al menos tres hallazgos, una figura y una referencia. Comprueba en el borrador de dónde sale cada cifra. Cierra y vuelve a abrir el proyecto después de aprobar los hallazgos. Entrega un DOCX editable y explica qué revisaste antes de exportarlo.

En el recorrido con TheAIWriter, puedes consultar `/theaiwriter:ayuda` o `/theaiwriter:estado`. El formador registra dónde pides ayuda y te deja seguir cuando la necesites.

## Comparación

Cada participante hace un ejercicio con TheAIWriter y otro equivalente con el mismo modelo, los mismos tipos de materiales y un buen prompt de redacción. Alterna el orden entre participantes. En cada recorrido registra:

| Medida | Cómo recogerla |
|---|---|
| Tiempo hasta el borrador editable | Desde que se abre la carpeta hasta que se obtiene el DOCX. Anota aparte la instalación. |
| Errores que llegan al DOCX | Compara cifras, grupos, unidades y afirmaciones con las fuentes antes de mostrar la corrección. |
| Tiempo para encontrar la evidencia | Pide que localice la fila, celda o página de tres afirmaciones. |
| Ayuda necesaria | Anota el momento, qué esperaba hacer y qué indicación le permitió seguir. |
| Exportación en Word | Comprueba que el DOCX abre, el texto es editable y se ven la figura, la cita y la bibliografía. |

Para una prueba final, modifica una copia del borrador de forma que el valor real de un grupo aparezca atribuido al otro. Mide si el participante lo detecta, localiza la fila correcta y sabe qué hacer con el DOCX anterior. Revisa también el caso de una figura cuyo archivo se ha movido.

## Criterio para continuar

El participante puede reanudar el proyecto, encontrar la evidencia y exportar un documento editable sin que le digan qué comando toca. Registra los errores científicos y las dificultades tal como ocurren, con el paso que falló y el resultado que se esperaba.
